# VulSight Models

This repository contains the trained models and pre-trained model artifacts developed as part of **VulSight**, a C/C++ vulnerability detection project based on deep learning.

## Available Models

### 1. VulSight-CNN-Devign
Trained CNN-based vulnerability detection model using the Devign dataset.

[**Access Model Files**](https://drive.google.com/drive/folders/13CrUB5CQU8Y7mNbA5tjfM9lOGJqS38LZ?usp=sharing)

### 2. VulSight-CNN-REVEAL

[**Access Model Files**](https://drive.google.com/drive/folders/1_2q1aZuMX0bHOjCQPfEG2fBKmNLMJgsc?usp=sharing)

### 3. VulSight-MLP-Devign

## Model Architectures

- **CNN (Convolutional Neural Network):** Captures local patterns in tokenized source code for vulnerability classification.
- **MLP (Multilayer Perceptron):** Performs vulnerability classification using a feed-forward neural network.
- **Pre-trained Model:** Learns source-code representations that can be fine-tuned for downstream vulnerability detection.

## Datasets

- **Devign**
- **REVEAL**
